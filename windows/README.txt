همین (Hamin) PMS — نسخه‌ی پرتابل ویندوز
=========================================

بدون نصب هیچ برنامه‌ای، کل سامانه (دیتابیس + ۸ سرویس + اپ) روی ویندوز خودتان اجرا می‌شود.

اجرا
----
1) این پوشه را در یک مسیر کوتاه و انگلیسی اکسترکت کنید، مثلاً:  C:\Hamin
   (مسیر فارسی یا داخل OneDrive/Desktop همگام‌شده توصیه نمی‌شود)
2) روی start.bat دابل‌کلیک کنید.
   - بار اول ۱ تا ۲ دقیقه طول می‌کشد (ساخت دیتابیس و داده‌ی نمونه).
   - اگر ویندوز برای Node.js یا PostgreSQL پیغام Firewall داد، Allow بزنید
     (برای اینکه با گوشی در همان وای‌فای هم بتوانید باز کنید).
3) مرورگر خودکار باز می‌شود:  http://localhost:8080

ورود
----
  ورود ساختمان (صفحه‌ی اصلی):
     مجتمع:       borj-aftab
     ایمیل:       admin@borj-aftab.test     (مدیر)
                  resident@borj-aftab.test  (ساکن)
                  guard@borj-aftab.test     (نگهبان)
                  staff@borj-aftab.test     (کارکنان)
     رمز:         Passw0rd!

  پنل سوپرادمین:  http://localhost:8080/super-admin/login
     behzad / 1234     یا     amir / 1234

توقف
----
  پنجره‌ی سیاه را ببندید، یا Ctrl+C بزنید، یا stop.bat را اجرا کنید.
  داده‌ها در پوشه‌ی data می‌مانند و دفعه‌ی بعد سر جایشان هستند.

شروع از صفر
-----------
  reset.bat  →  همه‌ی داده‌ها پاک می‌شود و دفعه‌ی بعد دیتابیس با داده‌ی نمونه از نو ساخته می‌شود.

باز کردن روی گوشی (همان شبکه‌ی وای‌فای)
-----------------------------------------
  IP کامپیوتر را پیدا کنید (در cmd:  ipconfig) و در گوشی باز کنید:  http://<IP>:8080

مشکلات رایج
-----------
  - «Port 8080 is in use»: برنامه‌ی دیگری از پورت ۸۰۸۰ استفاده می‌کند. در start.bat خط
    rem set PMS_PORT=8090  را بدون rem کنید.
  - سرویسی بالا نیامد: پوشه‌ی logs را ببینید (هر سرویس یک فایل لاگ دارد).

محدودیت‌های نسخه‌ی محلی
------------------------
  - RabbitMQ در این نسخه نیست؛ همه‌ی صفحه‌ها کار می‌کنند ولی رویدادهای بین سرویس‌ها
    (مثل ثبت خودکار لاگ ممیزی یا ارسال نوتیفیکیشن بعد از یک عملیات) منتقل نمی‌شوند.
  - فقط برای تست و دمو است؛ برای استفاده‌ی واقعی install.sh روی سرور لینوکس را اجرا کنید.
